# Diagramming Tools Infographic

This project is a small educational GitHub Pages site for computer science students.  
It explains common software diagramming tools, compares where they are typically used, and highlights why Mermaid is popular in development workflows.

## Project Files

- `index.html` - webpage content and structure
- `style.css` - responsive academic styling
- `infographic.png` - visual summary graphic

## Deploy with GitHub Pages

1. Push the repository to GitHub.
2. Open the repository on GitHub.
3. Go to **Settings** → **Pages**.
4. Under **Build and deployment**, set:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` and `/ (root)`
5. Save changes and wait for deployment.

Your site will be available at:

`https://<username>.github.io/diagramming-tools-infographic`
